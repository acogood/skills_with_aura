# Skills with Aura ✨

[English](README.md) · **Русский**

Небольшой набор скилов для [Claude Code](https://code.claude.com) — для маркетологов и контентщиков:
изучить аудиторию, поймать свой голос и превратить сырьё в посты для LinkedIn (и лонгриды) —
черновик, обогащение, ревью. Без API-ключей и без настройки сверх самого Claude Code.

## Как пользоваться скилом

Каждый скил — это обычная папка в [`skills/`](skills/). Чтобы установить, скопируйте её папку в
директорию скилов Claude Code:

```bash
git clone https://github.com/acogood/skills_with_aura
cp -r skills_with_aura/skills/linkedin-post-writer ~/.claude/skills/   # доступно везде
# …или только в одном проекте:  cp -r skills_with_aura/skills/<name> .claude/skills/
```

Дальше просто попросите Claude Code о том, что нужно — *«набросай пост в LinkedIn из этих заметок»* —
и он запустит подходящий скил; или назовите скил напрямую. Берите сколько угодно.

## Скилы — рекомендуемый порядок

Запускайте в любом удобном порядке; это просто флоу, который обычно работает. Каждый скил сохраняет
результат на вашу машину, а следующие скилы читают эти файлы.

**Настроить один раз — голос и аудитория**

1. **writing-style-analyzer** — скормите свои лучшие тексты; он сохранит переиспользуемую **Style Card**.
2. **content-audience-profiler** — соберёт исследовательский **профиль того, для кого вы пишете**.

**На каждый пост**

3. **talking-point-extractor** — превратите транскрипт, статью или заметки в готовые к посту углы.
4. **talking-point-curator** — отберите углы под вашу «полосу» и отранжируйте их в очередь постов.
5. **post-enricher** — добавьте историю, пример или проверяемую цифру, чтобы мысль реально зашла.
6. **linkedin-post-writer** — черновик поста в 2–3 вариантах под вашу Style Card и аудиторию.
7. **linkedin-post-reviewer** — блант-критика против того, что реально заходит, ещё до публикации.

   **Сделайте пост своим до публикации.** Не плодите ИИ-слоп — прочитайте пост целиком и перепишите плоские места в своём стиле: цепляющие хуки оставьте (они дают охваты), AI-тэллы уберите. Для отдельного прохода есть внешний скил **[humanizer](https://github.com/blader/humanizer)** (`npx skills add blader/humanizer`) — снимает признаки AI-письма; прогоняйте его **частично**, чтобы убрать тэллы, но не загладить хуки.

8. **linkedin-final-check** — последний гейт на выбранный вариант: вердикт SHIP/HOLD, что пост готов к публикации и без AI-slop.
9. **linkedin-meme-picker** — как пост прошёл final-check, превратите его в скролл-стоппер: мапит ваш хук и «священную корову», которую вы поддеваете, на подходящий шаблон memegen.link, проверяет, что картинка рендерится, и отдаёт мем-борд (лид + альты).

**В любой момент**

10. **lookalike-content** — прошерстите пачку успешных постов на то, что работает, и сгенерируйте свежие lookalike-идеи.

## Где сохраняется работа

Скилы читают и пишут в папку `content-workspace/` в вашем текущем проекте — всё остаётся на
вашей машине:

```
content-workspace/
├── profiles/        профили аудитории + style cards (общие для скилов)
├── samples/ sources/        ваши входные данные (примеры текстов, транскрипты/статьи)
└── talking-points/ content/ data/        сгенерированные углы, черновики, идеи
```

Для видео вставьте панель **Show transcript** из YouTube или положите файл субтитров в
`content-workspace/sources/` — сам Claude не умеет надёжно тянуть субтитры. См.
[getting-a-transcript.md](skills/talking-point-extractor/getting-a-transcript.md).

## Контрибьютинг

Скил — это папка в `skills/` с файлом `SKILL.md`: YAML-фронтматтер (`name` совпадает с именем папки,
плюс `description`, где сказано, что скил делает и когда его применять), дальше — тело инструкции.
Добавьте новый или заострите существующий и откройте PR.
